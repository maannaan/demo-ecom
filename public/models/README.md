# 3D Models Directory

Drop your custom `.glb` or `.gltf` 3D fashion assets here!

### Supported Naming Conventions:
- `void-runner.glb` or `sneaker.glb`: Overrides the default procedural sneaker in the 3D showroom.
- `phantom-shell.glb` or `garment.glb`: Custom architectural garment model.

### Recommended 3D File Specifications:
- **Format**: Binary GLTF (`.glb` preferred)
- **Geometry**: Centered at origin `(0, 0, 0)`, normalized scale
- **Target Polycount**: 20k - 60k triangles
- **Materials**: Physically Based Rendering (PBR) with separate materials for upper, sole, and accents to support dynamic colorway tints.
